# Code of Conduct

## Our standard

Everyone contributing to CheatGuard Central - code, issues, reviews,
documentation - is expected to keep the discussion technical and respectful.

**Do:**

- Critique code, not people.
- Assume competence and good intent in others.
- Keep exam-related data out of issues and pull requests (real student IDs,
  course codes, logs).
- Respect that this tool exists to protect exam fairness for students,
  invigilators and institutions alike.

**Don't:**

- Harass, insult, or discriminate (including via slurs or dogpiling).
- Publish other people's private information.
- Post exploit details or bypass instructions outside the private security
  reporting channel described in `SECURITY.md`.
- Use project channels to promote cracking tools or exam-cheating services.

## Scope

This applies to the repository (issues, PRs, discussions) and to any project
space (chat, calls) where you represent the project.

## Enforcement

Maintainers may remove comments, close contributions, or ban participants
who violate this code. Security-sensitive violations (posting bypasses,
credential material) result in immediate removal and, where appropriate,
reporting to GitHub. Appeals can be sent to the maintainer privately.

This code is adapted in spirit from the Contributor Covenant, version 2.1.
