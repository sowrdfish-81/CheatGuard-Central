# CheatGuard Central v1.9.7

## Monitor usability

- Back while monitoring now shows a dismissible warning instead of changing the
  monitor status or losing the live view.
- The active LAN IP and exam code are displayed separately and can be clicked
  to copy them to the clipboard.
- The running monitor keeps its connected-PC and alert data visible until Stop
  is pressed; code and network details remain locked during the run.
